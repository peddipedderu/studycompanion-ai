# StudyCompanion AI - Multimodal AI Hackathon 2026 Track D

A full-stack AI-powered study companion that helps students learn from PDF, PPTX, and video materials using RAG (Retrieval-Augmented Generation) with Google Gemini, adaptive quizzes with Bayesian Knowledge Tracing, and an intelligent chat tutor.

## Features

- 📁 **Multi-modal Upload**: PDF, PowerPoint (PPTX), MP4 video, plain text
- 💬 **RAG Chat Tutor**: Ask questions about uploaded materials with source citations (page/slide/timestamp)
- 📝 **Adaptive Quizzes**: MCQ, short answer, numerical — generated by Gemini from your content
- 🧠 **Bayesian Knowledge Tracing**: Per-topic mastery tracking that adapts over sessions
- 📊 **Dashboard**: Progress overview, mastery charts, weak topic alerts

## Stack

| Layer | Tech |
|-------|------|
| Backend | FastAPI + SQLite + ChromaDB |
| AI | Google Gemini 2.0 Flash |
| Embeddings | `text-embedding-004` |
| PDF | PyMuPDF (fitz) |
| Slides | python-pptx |
| Frontend | Tailwind CSS + Alpine.js (single HTML) |
| Deployment | Fly.io |

## Quick Start

### 1. Install dependencies

```bash
cd backend
pip install -r requirements.txt
```

### 2. Set API key

```bash
# Windows PowerShell
$env:GEMINI_API_KEY="your_key_here"

# Linux/macOS
export GEMINI_API_KEY="your_key_here"
```

### 3. Run

```bash
cd backend
python main.py
```

Open http://localhost:8080 in your browser.

## Bayesian Knowledge Tracing

The BKT model tracks P(know) per topic using:
- **P(init)** = 0.3 (30% prior knowledge)
- **P(learn)** = 0.1 (10% learning per attempt)
- **P(slip)** = 0.1 (10% chance to answer wrong when knowing)
- **P(guess)** = 0.25 (25% chance to guess correctly when not knowing)

Topics with P(know) < 60% are flagged as weak and targeted in future quizzes.
